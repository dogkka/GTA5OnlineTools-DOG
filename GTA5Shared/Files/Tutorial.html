快速上手

三步进游戏
版本说明：本项目同时支持 GTA5 增强版（Enhanced） 与 传承版（Legacy）：增强版内置自编译中文 YimMenuV2；传承版内置社区维护版 YimMenu（2026-07-17 构建，适配传承版 1.73 b3889）。游戏大版本更新后菜单可能暂时失效，需等待维护线跟进适配。
关闭反作弊：Rockstar 启动器 → 设置 → 我的已安装游戏 → GTA V Enhanced → 取消勾选 BattlEye。
（Steam：启动项加 -nobattleye；Epic：用 FSL 管理里的「无BE模式启动游戏」或桌面快捷方式）
安装 FSL：打开本程序 → YimMenu 页 → FSL 管理 → 点「一键安装FSL（自动检测）」——程序会自动识别 Steam / Epic 平台与增强版 / 传承版并安装。（内置官方 FSL V6，离线安装；装过 FSL 的用户会自动识别、无需重装）
注入菜单：游戏进入主菜单 → YimMenu 页 → 「增强版」卡片 → 点内嵌版 → 注入成功后屏幕中央播放「注入成功 · DOG」启动动画（约 8 秒），游戏内按 F7 呼出中文菜单（默认键，可自定义）。

呼出 / 关闭菜单

  • 默认按键：F7（适配小键盘；可自定义），备用 Ctrl + \
  • 自定义：菜单 → 设置 → 热键 → 点「呼出菜单」按钮后按你的按键

名词解释

  • 内嵌版：程序内置中文菜单 DLL，离线可用（推荐）
  • 网络版：原版从作者服务器下载，本版已禁用（不联网）
  • FSL：把线上存档重定向到本地，降低账号风险的组件

免安装使用

  • 单文件 exe，双击即用；覆盖旧版 exe 即完成更新
  • 配置与存档不受影响，完全离线运行

玩法指南：前置 · 等级 · 钱

前置跳过 · 刷等级 · 刷钱
先读这条：默认基于 FSL 本地存档（收益只保存在本地、不会同步云端）；主页 / FSL 管理支持切换「云端数据模式」（云同步，适合轻度辅助、慢慢积累；开启前需阅读使用须知）——两种模式自选。操作前先备份 %appdata%\FSL（切换数据模式时工具会自动再备份一份）；建议在邀请 / 私密战局进行；属于娱乐向功能，请自行评估风险。

传承版 · 先装玩法脚本（一次搞定）

  • ① 工具 YimMenu 页「传承版」卡片 → 点 安装脚本包（部署 汉化版 Ultimate Menu V3 + 注入动画到 %appdata%\YimMenu\scripts；首次注入时工具也会自动补齐，旧英文版会自动升级）
  • ② 注入菜单后，屏幕中央先播放「注入成功 · DOG」启动动画（约 8 秒）；随后游戏内按 F7 呼出菜单（默认键由工具首次自动写入，可在菜单 设置 → 热键 改），侧边栏出现 Ultimate Menu 1.73 By L7NEG 页签
  • ③ 没出现？菜单内 Scripts → Reload All，或重新注入一次

传承版 · 任务前置 / 分红 / 秒过

  • 位置：侧边栏 Ultimate Menu →「豪劫数据编辑器」（公寓 / 名钻赌场 / 佩里科岛 / 末日 / 科兹 / 赃车店…）
  • 「完成全部前置」=一键完成前置；「立即完成」=秒过终章
  • 分红：「应用分红」/「全员 - 100%」；收益：「主要收益」「出售价值」「提高规划板上限」

传承版 · 刷等级

  • 位置：Ultimate Menu →「恢复功能」→「设置等级」
  • 填目标等级（1-8000）→ 「设置等级」 → 切换一次战局生效
  • 另有「帮会等级」「全技能满级」同类页签

常见问题

遇到问题先看这里
提示「未发现 GTA5 进程」？
先把游戏开进主菜单，再回到工具点注入。
如何彻底卸载「小助手」？
打开工具 关于 页 → 点「一键卸载（清理配置与缓存）」→ 按提示清理完成后，删除程序文件（exe / 整个工具文件夹）即可完成卸载。清理范围：C:\ProgramData\GTA5OnlineTools、%appdata%\YimMenu、%appdata%\YimMenuV2 及桌面「GTA5 无BE启动」快捷方式；不会删除 FSL 本地存档（%appdata%\FSL）与游戏存档。游戏目录里安装过的 FSL 如需移除，请到「FSL 管理」操作。
注入失败？
点「内嵌版」报“未检测到游戏进程 / 检测到你正在运行的是…”？按提示对号入座： ① 玩增强版请点「增强版」卡片的内嵌版；玩传承版请点「传承版」卡片的内嵌版（点错卡片工具会直接提示你该点哪张）； ② 确保游戏已进入主菜单再点（启动器 / 加载阶段还没有游戏进程；游戏目录里的 GTA5_Enhanced_BE.exe 是 BE 启动器壳，实际游戏进程应为 GTA5_Enhanced.exe，且需要先关闭 BattlEye）； ③ 仍失败：主页「环境自检」→ 看「游戏进程」一项显示的是什么，再尝试以管理员身份运行本工具。
菜单呼不出来？
确认注入提示成功；游戏里按 F7（默认键；传承版 / 增强版同为 F7，可在菜单 设置 → 热键 改；增强版另有备用 Ctrl+\）；日志：传承版 %appdata%\YimMenu\cout.log、增强版 %appdata%\YimMenuV2\cout.log。
增强版和传承版，我该用哪个？
看你的游戏版本：增强版（Enhanced）用「增强版」卡片（内置自编译中文菜单）；传承版（Legacy）用「传承版」卡片（社区维护版 + Ultimate Menu V3 玩法脚本）。两个版本的小助手功能一致（数据模式、脚本包、任务 / 刷钱 / 等级玩法都支持）；不确定就先点主页「环境自检」，它会列出你电脑上装了哪个版本。
杀软报毒 / 文件被杀软删除了？
本类工具（注入器 + 菜单 DLL）被 360 / 火绒 / Windows Defender 误报是常态，属于误报。处理：① 在杀软里把小助手所在文件夹和 %appdata%\YimMenu、%appdata%\YimMenuV2、C:\ProgramData\GTA5OnlineTools 加入白名单 / 信任区；② 若文件已被删，从杀软隔离区恢复，或重新打开小助手自动重新释放菜单文件；③ 仍异常：主页「环境自检」看哪一项缺失。
功能点了没反应 / 想反馈问题，怎么给信息最快？
先点主页「环境自检」→「复制结果」（或「生成反馈包」在桌面生成压缩包）→ 把内容 / 压缩包发到 QQ 群（备用2群：1129626000）。反馈包含自检结果 + 日志 + 关键配置，能直接定位问题，比截图高效得多。

呼出菜单后鼠标被锁在屏幕中心？（个别环境）
菜单 2.1.37 已修复：打开菜单时自动解除光标钳制（ClipCursor）。若仍偶现：① 游戏设置 → 鼠标 / 键盘 → 输入方式改为「原始输入」；② 按一次 Alt+Tab 或 Alt+Enter 切一下窗口即可恢复。
FSL 安装失败？
先关闭游戏再安装；确认游戏目录有写入权限。卸载：FSL 管理 → 移除对应平台的 FSL。
装过 FSL，更新小助手后要不要重装？
不用。装过 FSL 的用户直接打开游戏 → 点「内嵌版」注入即可。FSL 管理页顶部会显示检测结果：内置同款会提示「无需重复安装」并自动跳过；检测到其他版本会先弹窗询问，更新前自动备份旧文件与本地存档。小助手不会删除 %appdata%\FSL 里的任何存档。
FSL 存档在哪？怎么备份？
存档与配置都在 %appdata%\FSL（资源管理器地址栏输入 %appdata% 回车即可打开）。备份：FSL 管理 → 点「备份FSL存档」；另外切换数据模式、更新 FSL 版本时都会自动备份到 C:\ProgramData\GTA5OnlineTools\Backups（保留最近 10 份）。换电脑拷贝整个 FSL 文件夹即可。
以前玩传承版（本地存档），换增强版后进度没了？
两种版本的存档文件名不同：传承版为 save_char0001.pso，增强版为 save_char0001_pcrosalt.pso。社区做法：把 %appdata%\FSL 里的 .pso 文件复制一份、文件名加 _pcrosalt 后缀即可让增强版读取（反过来去掉后缀即回到传承版）。操作前先备份整个 FSL 文件夹。
Epic 平台提示「需要启动 BE 反作弊」进不去游戏？
Epic 启动器不会给游戏传启动参数，因此关闭 BattlEye 后会被拦。解决：FSL 管理 → 点「无BE模式启动游戏（Epic适用）」；或点「生成无BE桌面快捷方式」，以后双击桌面快捷方式启动（等效于 Steam 的 -nobattleye 启动选项）。
弹出 DirectX 错误 / 内存不足（ERR_GFX_D3D_DEFERRED_MEM）？
经崩溃转储核实为游戏自身 D3D12 显存分配失败（游戏自己的问题），可尝试在游戏设置里关闭「帧生成」，或降低画质后重启游戏。
部分功能「不生效」？
伤害事件类整蛊对开启了防护的目标无效（被对方拦截，属正常）；整蛊 / 遥控类功能对正在被对方驾驶的载具存在同步限制，等他下车后即可生效。请用无防护小号验证功能本身。
游戏更新后菜单失效？
需要等待适配新版游戏的菜单 DLL 发布（本版本完全离线，不联网自动更新）。
